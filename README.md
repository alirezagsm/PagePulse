<p align="center">
Reload the active Firefox/Chrome/Edge tab at a specified interval.
 
</p>

## Install on Firefox 🛠️

Download and drag `PagePulse.xpi` onto Firefox.

## Install on Chrome/Edge 🛠️

1. **Clone or Download** this repository.
2. Open the browser and navigate to **Extensions**.
3. Enable **Developer mode** by toggling the switch in the top right corner.
4. Click on **Load unpacked** and select the **PagePulse_Chrome** directory.

## Usage 🚀

1. After installation, **click on the extension icon** in the toolbar.
2. In the popup, **set the reload interval** in seconds.
3. Click **Start Reloading** to begin the cycle for the active tab.
4. Click **Stop Reloading** to pause the automatic refresh.
